# 🎨 ChromAI
ChromAI is an AI that determines and guesses on what color it is based on visuals such as media uploads, live web cam, manual input, and etc. Currently I'm developing this AI to take a step on the AI engineering world and I'm using Python for that purpose

## Goals
- Create a reliable AI and train it to see colors and generate a response
- Able to handle complex colors and make the best guess
- Integrate to a indiviual website for users to try out publically
- Creating APIs and materials for public usage

## Stack
- Python

## Libraries
- Math
- PathLib
