# 🎨 ChromAI

**An experimental color recognition and classification project built with Python.**

ChromAI is a learning-driven AI project focused on teaching machines to recognize and classify colors from RGB values, images, and eventually real-time camera input.

The project explores the fundamentals of machine learning, dataset preparation, model training, evaluation, and computer vision while gradually evolving into a more capable color recognition system.

> **Status:** Under Development 🚧

## 🎯 Project Goals

- [ ] Develop a reliable machine learning model for color classification.
- [ ] Recognize and classify colors from RGB values.
- [ ] Support complex shades and similar-looking colors.
- [ ] Introduce image-based color recognition.
- [ ] Implement real-time color recognition through webcam input.
- [ ] Develop a public-facing web application.
- [ ] Build APIs and tools for external developers.

## 🧠 Machine Learning

ChromAI is currently experimenting with classical machine learning techniques.

The initial approach uses:

- RGB values as input features.
- Color categories as classification labels.
- K-Nearest Neighbors (KNN) for classification.
- Dataset splitting and augmentation.
- Model evaluation using accuracy, precision, recall, and F1-score.

The project is still in its early stages. Model performance and reliability are continuously being evaluated.
